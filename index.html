Questions.

Is this an IDE?

Yes, the next one: you read your repository as a blueprint instead of line by line, and it's built so you can hand an agent context in a click and the agent finds the rest itself.

Do I still need my editor?

Keep it if you like; any line in the blueprint opens there.

How does it work with agents?

Pick any section, box or line and it goes to Claude as context, and Claude reads the blueprint to find the code it needs.

Does my code leave my computer?

Only to your own Claude Code, as it would anyway; the blueprint stays on your machine.

What do I need?

A Mac or Linux desktop and Claude Code on a Claude plan.

What does it cost?

Making a blueprint uses your Claude plan, like any Claude Code session.

Which languages does it read?

TypeScript, Python, Go, Rust, Java, Swift and most other major languages, plus SQL, Prisma, GraphQL and protobuf.

What's proven and what's a guess?

Solid lines came from the code; dashed lines and cards marked inferred didn't.

What happens when the code changes?

Only the sections whose code changed are redone; the rest stays put.
